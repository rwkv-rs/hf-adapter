# Apple M5 supporting benchmark rows

This bundle groups the previously standalone Apple Silicon, MLX, MPS,
quantization, clean-install, and production-gate rows retained by the benchmark
manifest. The files were moved here without rewriting their contents. The
active gate definition remains at `../apple_production_gates.json`; its proof
paths point into this bundle.

These rows support the promoted Apple M5 B1/B8 bundles.  They are not a claim
of portability to other Apple chips or memory capacities.
