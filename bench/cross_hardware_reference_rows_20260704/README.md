# Cross-hardware reference rows

`results.jsonl` is the original aggregate development result stream covering
V100, RTX 4090, A100, A800, RTX A6000, RTX 5090, and additional smoke devices.
It is retained as supporting reference data and is not the source of current
promoted per-card claims.  Current claims use the dedicated evidence bundles
listed in `../CURRENT_ARTIFACTS.json`.

The JSONL payload was moved from the `bench/` root without modification.
